# 变更记录

## 2026-11-24 支持 Loon 规则列表与四方互转

增加 `Loon/` 目录下的 `.list` / `.conf` 规则可视化编辑与新建模板，支持在 Clash、QuantumultX、Shadowrocket、Loon 四种规则格式之间互相转换。

## 2026-11-17 每个文件只保留一条令牌

再次生成会先作废上一条，界面和 KV 都只保留最新的一条。批量时每个文件仍各一条。

## 2026-11-17 令牌显示过期时间

按令牌后 6 位分钟数推算到期时间，从 2026-01-01 00:00 UTC 起算。000000 显示为永久有效。

## 2026-11-17 打开令牌面板即回显

点击分享图标后，弹窗一打开就读取已保存的令牌，并显示在「令牌链接」最上方。

## 2026-11-17 访问设置显示实际规则

打开访问设置时按这条路径真正生效的规则选中，不再总是停在「继承上级」。目录规则 `dir/` 与 `dir/**` 视为同一条。

## 2026-11-17 分享图标打开令牌

仅令牌访问的文件或目录，点击分享图标会打开令牌面板：已有令牌直接回显，也可以再生成。眼睛和锁仍进入访问设置。

## 2026-11-17 文件树权限图标统一

可以直接访问时悬停显示眼睛，令牌访问默认显示分享图标，不能访问默认显示锁。目录和文件使用同一套规则。

## 2026-11-17 文件树访问按钮改为悬停图标

目录和文件行的「访问」改为图标，鼠标移到该行才显示。触屏上保持可见。

## 2026-11-17 保存并回显已生成令牌

签发的令牌写入 KV，按文件保存。再次打开「获取文件链接」会显示仍有效的令牌。撤销该文件或全部链接后不再回显。没有绑定 KV 时仍可签发，只是不能回显。

## 2026-11-17 隐藏不可访问的直链

获取文件链接时，私有仓库的 GitHub / jsDelivr、未开启的公开代理、以及未设为免令牌直链的 Worker 地址不再显示。

## 2026-11-17 令牌链接结果分卡显示

单文件生成后分成路径式链接、查询参数链接和令牌三张卡片，地址单独换行，复制按钮固定在标题右侧。批量结果按文件列出。

## 2026-11-17 当前文件可以直接生成令牌

打开文件后获取链接时，未加入白名单的文件会先写成仅令牌再签发，不再提示没有可生成的文件。刚保存的规则会留在本次读取缓存里，避免马上又读到旧规则。

## 2026-11-17 文件树直接设置访问规则

每个目录和文件都有固定的访问按钮，不会被文件名挤掉。搜索时也会列出匹配的目录，方便直接改规则。

## 2026-11-16 目录文件可设令牌

目录规则 `dir/` 会覆盖其中的文件。生成令牌时如果这些文件还没开放，可以确认后把该目录或该文件设为仅令牌再生成。文件树上每个文件也能单独设置访问。

## 2026-11-16 文件树访问角标

不能直接访问的文件显示锁，允许令牌访问的显示分享图标，能直接访问的不显示。未配置规则时不再默认显示链接图标。

## 2026-11-16 原始内容可切换高亮语言

编辑器工具条增加语言选择。留在「自动检测」时按文件识别；选中某语言后固定使用该高亮，打开另一个文件会回到自动检测。

## 2026-11-16 管理界面改为 Vue + Vite

客户端用 Vite 构建，界面改为 Vue 3、Tailwind 和 Reka UI，编辑器改为 CodeMirror。解析器移到 `shared/`。部署资产改为 `dist/client`。
